# TinySteps – AI Usage Disclosure

AI tools were used as support during the project. All AI-generated content was reviewed, revised, and finalized by the team.

## ChatGPT
- Used as a support tool to refine the architecture diagram and clarify the responsibilities of each layer. We reviewed its suggestions, adjusted the diagram to match our actual implementation, and finalized it ourselves.

## Gemini
- Used to help identify the libraries used in TinySteps and draft explanations of  their roles. We reviewed the suggestions against our project materials, requested revisions where needed, and updated the content.
- Used to help structure the feature walk-through for the `My Tasks` screen and format the GitHub evidence. We reviewed the generated structure, updated the class and function names to match our actual app implementation, and finalized the content.
