## ER Diagram – TinySteps

I was responsible for designing the ER Diagram for the TinySteps database in Milestone 3-A.

The diagram includes seven main entities: Parent, Child, Task, TaskStep, TaskAssignment, StepProgress, and PairingCode.

I defined the relationships between these entities, including primary keys (PK), foreign keys (FK), and cardinalities (1:N and M:N), ensuring the design aligns with the application’s features and database requirements.
